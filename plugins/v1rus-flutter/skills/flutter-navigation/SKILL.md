# Navigation (go_router, typed routes)

## Typed routes, not strings

Routes are declared as `GoRouteData` subclasses annotated with `@TypedGoRoute` and generated by
`go_router_builder`. The point is not ergonomics — it is that **`int.parse(state.pathParameters['id']!)`
is a runtime crash that the compiler cannot see**, and typed routes delete that whole class of bug.

```dart
// features/orders/routes/order_routes.dart
@TypedGoRoute<OrderDetailsRoute>(path: '/orders/:id')
class OrderDetailsRoute extends GoRouteData {
  const OrderDetailsRoute({required this.id});
  final String id;

  @override
  Widget build(BuildContext context, GoRouterState state) => OrderDetailsScreen(id: id);
}

// call site — the compiler enforces the parameter
OrderDetailsRoute(id: order.id).push(context);
```

Rules:

- **No raw path strings at call sites.** `context.push('/orders/${order.id}')` is banned: it silently
  survives a path rename.
- Complex objects are **not** passed through a route. Pass an id and let the destination load; a route is
  a URL, and it must survive a cold start from a deep link where no object exists in memory.
- Query parameters for optional filters, path parameters for identity.

## Ownership: feature owns routes, root assembles

- Each feature declares its own routes in `features/<name>/routes/`. This is the only part of a feature
  that is public (`flutter-architecture`).
- The `GoRouter` is constructed **once** in the composition root, listing the generated route trees. No
  feature builds a router, and no feature imports another feature's route file — cross-feature navigation
  goes through a route declared in the destination feature, which is reachable because routes are the
  feature's public surface.
- A `ShellRoute` / `StatefulShellRoute` is used for persistent bottom navigation, so tab state survives
  switching. Do not rebuild a tab scaffold per route.

## Auth gating — one redirect

Authentication is enforced in the router's **single `redirect`**, driven by the session state exposed from
`core`. One place decides "not authenticated → login", "authenticated on login screen → home".

Per-screen `if (!loggedIn) Navigator.push(...)` checks are banned: they race, they double-navigate, and
they miss deep links entirely. When the session-expired channel fires
(`flutter-networking`), the root reacts once and the redirect does the rest.

Make sure the redirect cannot loop: the login route itself must be reachable while unauthenticated, and
the "already authenticated" branch must not send the user back to a guarded route that redirects again.

## Dialogs, sheets and results

- A dialog or bottom sheet that is part of a **flow** (a picker whose result drives the screen, a confirm
  step, anything deep-linkable) is a **route** — it gets back-button handling and state restoration for
  free.
- A purely local sheet with no navigation meaning may be shown inline; then its state is a `Cubit`
  (`bloc-conventions`).
- A result travels back as the awaited value of `push` at the **widget** layer, which then dispatches an
  event to the Bloc. **A Bloc never awaits navigation and never holds a `BuildContext`** — it emits an
  effect asking for navigation, and the widget performs it.
- **Dismissal without a choice is a valid outcome.** Handle the `null` result explicitly rather than
  treating it as "nothing happened", or the user's cancel becomes a silently swallowed action.

## Deep links

Treat a deep link as a normal entry point: the app may start **cold** directly on that route, with no
authenticated session and no preloaded data. Every route's screen must therefore be able to load
everything it needs from its parameters, and handle loading / not-found / unauthorized itself
(`flutter-ui-conventions`).

## Version discipline

`go_router` is feature-complete but has had breaking changes across majors (17.0.0 among them), and
`go_router_builder` must match the `go_router` the project resolves. Check the migration notes for the
resolved version before writing router code, and never pin a remembered version — resolution happens at
plan time (`v1rus-dependencies`).
